# 115年臺中市分齡足球友誼賽暨國際足球邀請賽

直接開啟 index.html 即可瀏覽，不需要安裝套件或啟動伺服器。發佈時，將根目錄的九個 HTML、`css/`、`js/`、`主視覺.jpg`、`logo.jpg`、競賽章程 PDF 及 `assets/` 資料夾一併上傳。`範例/` 資料夾不屬於新網站。

本網站使用**獨立的樣式與腳本**：九個正式頁面載入 `css/site.css` 與 `css/theme-2026.css`，球隊介紹頁另載入 `css/teams.css`、`js/team-data.js` 及 `js/teams.js`；賽程頁另外載入 `css/schedule.css`、`js/schedule-engine.js`、`js/schedule-groups.js`、`js/schedule-bracket.js` 及 `js/schedule.js`；所有頁面均載入 `js/site.js`。

## GitHub Pages 發布
1. 使用新版 `GitHub-Pages-新版主視覺與FB公告.zip`，解壓縮後**上傳全部內容**，不要只上傳 ZIP 本身。舊的 `GitHub-Pages-完整發布版.zip` 是修改前的版本。
2. GitHub 儲存庫的 `main` 分支根目錄應直接看到 `index.html`、`css/`、`js/`、`assets/`、主視覺圖、Logo、各 HTML 頁面及章程 PDF。不要多包一層資料夾，也不要上傳 `範例/` 或 `.qa/`。
3. 到 GitHub 儲存庫 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**，**main**、**/(root)**，並儲存。
4. 上傳完成後檢查瀏覽器開發者工具的 Network：`css/site.css`、`js/site.js` 與圖片應回傳 200，不應再出現 404；如仍看到舊畫面，請重新整理快取。

## 維護
目前為純靜態網站，無後台或假比分。比賽賽程與比分會由公開 Google 試算表同步，需要連網；小組分組與隊名已固定在本地程式內，離線時仍能查看完整 11 組、39 支隊伍的分組圖，比分與積分更新則需連網。
更新參賽球隊：每隊在 `assets/球隊介紹/隊名/` 底下放置 `介紹.txt` 和任意層級的 JPG/PNG/WebP 照片，執行 `python scripts/build-team-data.py` 即會重新產生 `js/team-data.js`；正式發布時將新資料檔與照片一起上傳。純靜態 `file://` 網站不使用瀏覽器即時讀取文字檔，因為本機瀏覽器通常會阻止此類讀取。
香港熱火體育會沿用先前 Facebook 公告的本地圖片及原文連結，直接與素材資料夾內的 15 隊並列。舊的「足夢DTEAMU15」公告已從頁面移除，素材資料夾的「足夢DTEAM」仍以資料夾內提供的新介紹獨立呈現。
更新賽務文字公告：編輯 `announcements.html`「賽務資訊與提醒」及 `index.html` 的「大會最新消息與公告」區塊。
更新時程：同步修改 js/site.js 的 milestones 與 event-info.html 流程。
更新正式賽程：直接編輯 [大會賽程 Google 試算表](https://docs.google.com/spreadsheets/d/1ftHNzPYCmHHl9611hHOHmX5H6WUHiQ8h9PkPhUUlfcc/edit?usp=sharing)。工作表名稱使用 U6、U8、U10、U12、U15，每頁前兩列為標題及表頭，欄位為日期、時間、場地、場次、歲組、隊名、成績、隊名。日期可以只填一天第一筆，會向下延用；「開幕」等非對戰場次以活動卡呈現。賽程頁每 30 秒自動檢查更新，沒有手動重新整理按鈕。切換參賽歲組會回到比賽賽程分頁，日期只顯示年月日，場地標籤位於卡片最右側。成人組上傳前保持等待公告。
固定分組名單：2026-11-26 直接讀取上述 Google 試算表各頁右側的分組欄（U6 的 L/M、U8 的 K/L/M、U10/U12/U15 的 J/K），已核對 11 組、39 隊，完整名稱寫死在 `js/schedule-engine.js` 的 `GROUPS`。日後修改試算表的分組欄不會自動改變網站隊名；要更動分組，必須編輯該本地常數。賽程只讀試算表 A–H 欄的時間、場次與比分。
小組圖：`js/schedule-groups.js` 使用固定名單畫出學童盃風格的三角／方形對戰圖，依同組對戰場次將比分寫在相應邊線上。積分表顯示賽、勝、和、敗、進球、失球、積分（勝 3／和 1／敗 0），不顯示淨勝球欄或積分規則小字。同分依相關隊伍勝負關係→相關淨勝球→相關進球數→全組淨勝球→全組進球數→公平競賽判定；小組賽全部完成且沒有未解同分時才確定名次與 A1/A2 籤位，避免假晉級。
淘汰賽場次依大會手繪固定：U8 附加賽 16（C1 vs B2）、17（A2 vs C2），準決賽 18（A1 vs 16勝）、19（17勝 vs B1），季軍戰 20（18敗 vs 19敗），冠軍戰 21（18勝 vs 19勝）；U10 的準決賽為 7/8、季軍戰 9、冠軍戰 10；U12 為 13/14、15、16；U6、U15 為 10/11、12、13。固定籤位在 `js/schedule-engine.js` 的 `BRACKET_CONFIG`，`buildFixedBracket()` 處理分組排名、比分、勝敗、OT 與 PK，左右對戰方序以手繪為準，試算表若採反序則自動對應比分。`js/schedule-bracket.js` 依 `/2026/live-draws.js`「學童盃」的實際實作：場次編號置於橫線下方、比分固定在編號下；有正式比分的場次才由底部開始播放黃綠光線及光點，兩隊交會後揭露比分、淘汰敗隊光線淡出；沒有登錄比分的場次維持靜態白線、不出現光點、不向後續場次預先晉級；季軍藍線待兩場準決賽完成才解鎖，季軍戰有比分後才播放藍色光線。縮放控制同學童盃：適合按鈕依圖寬自動縮放並置中、範圍 20%–240%、± 每次 1.25 倍、Ctrl+滾輪/雙指捏合以指標位置為中心、單指拖曳、保留手動縮放與捲動位置；另外支援桌機滑鼠拖曳。電腦版階梯圖面板最大寬度 1100px、預設 fit 倍率再減少約 10%，手機縮放不變。偏好減少動態效果的裝置會直接揭露比分。未賽及未決排名顯示 A1/B1 等籤位，不虛構勝隊或比分。
導航與頁尾直接寫入各 HTML；調整共同導航時請同步九頁。
所有核心圖片均為本機素材，無須外部字型或 CDN；香港熱火體育會的 Facebook 原文連結需要網路。
正式網站上線後可將 og:image（目前為 `主視覺.jpg`）改成正式站的完整絕對網址。
